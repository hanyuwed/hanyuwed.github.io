# HanyuWed

Карточки, словари, аудио и упражнения по китайскому, французскому, корейскому, арабскому, итальянскому и испанскому языкам. Интерфейс и переводы доступны на русском и узбекском.

[Открыть HanyuWed](https://hanyuwed.github.io/)

Для французского и корейского курсов записи сгенерированы локально голосом F1 модели Supertone Supertonic 3. На сайт загружаются только MP3 и их указатели. [Модель](https://huggingface.co/supertone-oss-archive/supertonic-3/tree/aafc6e32416a594460b32413efc49d7fe4ce6d46) · [Лицензия](https://huggingface.co/supertone-oss-archive/supertonic-3/blob/aafc6e32416a594460b32413efc49d7fe4ce6d46/LICENSE)

Проверка данных перед публикацией запускается командой `node scripts/check-data.mjs` в Node.js 22 или новее.
